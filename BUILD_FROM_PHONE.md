# Build Fixora APK from your phone

1. Upload/replace the changed files in the GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Fixora Android APK**.
4. Tap **Run workflow** on the `main` branch.
5. Wait for the workflow to finish.
6. Open the completed workflow run.
7. Under **Artifacts**, download `fixora-android-apk`.
8. Extract the downloaded ZIP and install the `.apk` on Android.

No computer and no QR code are required for this build flow.
